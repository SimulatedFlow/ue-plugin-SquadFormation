# SquadFormation — AI Group Movement & Formation Steering

A C++ formation-movement and group-steering framework that moves AI squads and companions in coherent, obstacle-aware formations on top of the Navigation System — with formation shapes, automatic slot assignment and navmesh-projected group moves.

Supports **Unreal Engine 5.8**. Full C++ source included.

Documentation: <https://wiki.teufel-engineering.com/en/SquadFormation> — installation, quick start and the API. `Docs/Fab-Store-Description.md` holds the store listing text.
